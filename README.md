## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Ayush-sharma7/Java-with-Ayush.git
cd Java-with-Ayush
```

Compile a program:

```bash
javac BubbleSort.java
```

Run it:

```bash
java BubbleSort
```

Replace `BubbleSort` with the name of the Java class you want to execute.
